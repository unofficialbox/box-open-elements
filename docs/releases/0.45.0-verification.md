# 0.45.0 release preparation

Prepared from main `e3e5172afcf1619968d71c15b05dd23349ab4f01` after chart PR #613. This change contains release metadata, documentation and the registry-pin catch-up; chart runtime behavior is unchanged.

## Package alignment

Core and React, Angular, Vue, Svelte, SolidJS and Preact adapters are `0.45.0`. All seven workspaces that peer on core require `^0.45.0`; Box Server retains its independent `0.1.0` version. README documentation links target `v0.45.0` and the changelog includes the nullable chart-point migration, distribution-part changes and optional-animation defaults.

The first aggregate attempt correctly rejected the old `0.43.0` registry pin. Bun refreshed that entry to the already-published `0.44.0`; its temporary root self-dependency was removed. Frozen installation, lockstep and release-compatibility guards passed without weakening their rules. The pin may lag this unpublished candidate by one release, as RELEASING.md specifies. A separate pin-refresh PR is still required after `0.45.0` is public.

## Publication and coverage limits

Preparation does not publish a package or create a tag/GitHub Release. After approval and merge, the existing Cut release workflow must publish core before the six adapters. Registry versions, installed consumers, provenance and the mandatory final pin refresh must be checked after publication; local archives do not establish npm provenance.

Manual screen-reader and physical-device chart testing remain unfinished. Existing Chromium chart acceptance and pinned Firefox adapter/table/reflow checks do not establish an all-chart Firefox or manual screen-reader pass. The tree/diff manual screen-reader limitation recorded for `0.43.0` also remains documented.
